# Vtronix V2: repo audit

Written before any V2 content changes, per the addendum. Covers stack, data storage, reusable patterns, fonts/colors/spacing, and the image inventory.

## Stack

- Plain static HTML/CSS/JS. No framework, no bundler, no `package.json` in the shipped site.
- Deployed on Vercel as a static site (`vercel.json`: `cleanUrls`, redirects, rewrites).
- Product and category detail pages are pre-generated by `scripts/generate-product-pages.py`, which writes one static file per product under `products/<slug>.html` from a Python list literal (`PRODUCTS`, ~1120 lines, 98 entries) at the top of the script. There is no separate JSON/CSV data file today; the addendum's per-product `source_page` requirement means this needs a real data file (see Part 5 notes below), not more inline Python.
- `products.html` renders the category/all-products listing and filtering client-side from a JS data blob (see `assets/js/main.js` and inline data in `products.html`), matching the brief's description of `products.html?cat=`.

## Fonts

- `Montserrat` (weights 300/400/500/600/700) via Google Fonts, falling back to Arial/Helvetica/sans-serif (`--font`).
- Type scale is all `clamp()`-based custom properties: `--fs-eyebrow` 13.5px, `--fs-body` 17px, `--fs-lead`, `--fs-h3`, `--fs-h2`, `--fs-h1`, `--fs-hero`.

## Colors

Dark theme, defined as CSS custom properties on `:root`:

- `--black` #000000, `--near-black` #060708, `--panel` #0c0d0f, `--white` #ffffff
- `--blue` #4a9bdc, `--blue-bright` #6ab6f2, `--blue-dim` #35688f, `--blue-glow` rgba(74,155,220,.35)
- `--gray-text` #a9a9a9, `--gray-soft` #9099a1, `--gray-line` rgba(255,255,255,.18), `--gray-line-soft` rgba(255,255,255,.09)

No new colors, gradients, or shadows are introduced in V2 per the addendum.

## Spacing scale

`--sp-1` 8px, `--sp-2` 14px, `--sp-3` 22px, `--sp-4` 34px, `--sp-5` 54px, `--sp-6` 88px. `--max-width` 1280px, `--gutter` clamp(20px, 5vw, 64px). Transitions use `--ease` (cubic-bezier(0.22,0.61,0.36,1)) and `--dur` (0.45s).

## Reveal-on-scroll

Sections use an IntersectionObserver-driven `opacity`/`transform` reveal (see `assets/css/style.css` "Reveal-on-scroll" block and `assets/js/main.js`). This must be accounted for when scripting screenshots (a full-page capture without first scrolling through the page renders later sections blank) and should be the only entrance animation used on new sections, per the addendum's "reuse existing hover/reveal effects" rule.

## Content issues already visible (to fix in Phase 2, not here)

- Homepage "Why Choose Us" block uses "pioneering" and "state-of-the-art" — both on the addendum's banned-word list (section 6). Rewrite when Home is rebuilt.
- Homepage still has the "Products & Links" numbered block the brief says to remove.
- Footer product links use old query-string category slugs (`products.html?cat=thermostats-residential`, etc.) and `contact.html` instead of `contact-us.html`. These need to move to the Wix-parity URLs as part of Phase 1, not Phase 2, since Part 1.4 of the brief requires internal links to always use final URLs.

## URL map cross-check (repo vs. `vtronix-url-map.json`)

Full findings and live-sitemap reconciliation are in `URL-REPORT.md`. Headline items relevant to the audit:

- The repo has 98 generated product pages against the crawl's 93 products; 5 are not in the map (`vc8011zz00`, `vczal1100`, `vczar1100`, `vu444a1007`, `vu52s2028` — all Honeywell resale items) and need verification against the live Wix sitemap.
- At least 13 product slugs in the repo differ from the Wix slug in the map (for example `products/w100.html` vs. map's `w100-1`; `products/tb7980b1005.html` vs. map's `tb7980b1005-honeywell-zonepro-modulating-thermostat`; every `-obsolete` discontinued item is missing that suffix in the repo). These must be renamed to match Wix exactly, with the old slug 301-redirected.
- Manual PDFs are linked directly to `usrfiles.com` and `s3.amazonaws.com` addresses in the generator's `docs` field, not self-hosted under `/manuals/`, which the brief requires (Part 1.5) and the addendum's QA pass explicitly checks for.
- `cat_query` values in the generator (`thermostats-residential`, `fan-coil-controls`, `discontinued-items`) are the old Vercel slugs, not the Wix category slugs the URL map calls for.
