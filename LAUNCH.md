# Vtronix V2 launch checklist

1. Lower web-record DNS TTL one day before cutover. Leave MX and all mail records unchanged.
2. Attach both `vtronix.com` and `www.vtronix.com` to the Vercel project, set `www` as the primary domain, and confirm the apex → `www` redirect in `vercel.json` fires (it depends on both domains being attached; it could not be exercised in local dev).
3. Verify SSL, then run `python3 scripts/check-urls.py https://www.vtronix.com vtronix-url-map.json` (point it at the merged/complete map — see `URL-REPORT.md`) and confirm every URL is a 200 or a single 301 to a 200. As of the Phase 1 preview, 116/118 mapped URLs are single-hop 200s; the 2 that aren't are legacy `/products.html?cat=` query links that were never real Wix URLs (see `URL-REPORT.md` for why, and confirm they still don't matter before launch).
4. Confirm `robots.txt`, `sitemap.xml`, canonical tags and analytics are production-ready. Note: `sitemap.xml` is regenerated by the Vercel build command (`vercel.json`) but Phase 1 only seeded it with the 6 core pages, 8 categories and 98 products that have real content today — re-run `scripts/generate-sitemap.py`'s static-page list needs the later phases' new pages (Custom Controls, Applications, etc.) added once they ship.
5. Confirm Vercel's default preview-deployment `X-Robots-Tag: noindex` header is present on the preview URL (no custom middleware was added for this — Vercel sends it automatically) and confirm production does not have it.
6. Submit the production sitemap through Google Search Console.
